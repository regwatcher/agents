# Senior Backend Engineer (Python)

## Company

Example Labs builds workflow automation for operations teams. Remote-first, EU time zones preferred.

## Role summary

We need an experienced backend engineer to design and ship APIs, integrate third-party services, and improve reliability of our Python services.

## Responsibilities

- Design and implement REST and async APIs (FastAPI or similar).
- Own PostgreSQL schema evolution and query performance.
- Add observability (structured logging, metrics, tracing).
- Collaborate with product on technical trade-offs and timelines.

## Requirements

- 5+ years professional software development, mostly backend.
- Strong Python (3.11+), typing, testing (pytest).
- Production experience with SQL databases and migrations.
- Comfortable with Docker and CI/CD basics.

## Nice to have

- Experience with OpenAI / LLM integrations or agent frameworks.
- Previous work in regulated or audit-heavy environments.

## Location & contract

Remote (EU). Full-time employee or long-term contractor.

## How we interview

1. Short technical screen (take-home or live coding, your choice).
2. System design conversation focused on a real feature from our stack.
3. Culture / ways-of-working chat with the team lead.
